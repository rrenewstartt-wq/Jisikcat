# 전기값이 마이너스면, 세탁기 돌린 집이 돈을 받을까?

**2분 18초 한국어 파일럿**에서 2024년 5월 12일 독일·룩셈부르크 하루 전 전력시장의 가격을 따라간다. 오후 1시 거래가격을 가정에서 쓰는 단위로 환산한 뒤 서로 다른 소매 계약 두 개에 같은 가격을 대입한다. 숫자는 실제 도매가격과 가상의 소매 단가로 나누어 화면에 표시했다.

## 제작과 재생성

한국어 내레이션 30개에 세탁기·발전소 촬영본, 시간별 가격 애니메이션, 음수 가격 정산 도해, 소매 계약 영수증을 맞췄다. `edit/motion/`이 현재 마스터의 제작 소스다. [렌더 재생성 방법](edit/motion/README.md) · [실사 원본과 라이선스](edit/motion/footage.json). `python3 episodes/ep-001-power/edit/render.py`로 촬영본을 준비하고 현재 마스터와 썸네일을 재생성할 수 있다.

## 검수 상태

레퍼런스 분석만 하네스에 접수됐다. 선정작의 원본 영상·한국어 자막·표지 파일 확보가 대기 중이며, 15분 기획에서 핵심 설명을 압축한 이번 파일럿과 장편 전체의 동급 판정도 보류 중이다. 출고 승인과 게시 이력은 없다. 저장소 루트에서 `python3 tools/studio.py status ep-001-power`로 회차 상태를 조회한다.
