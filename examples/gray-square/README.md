# 같은 회색이 두 색처럼 보이는 이유

지식 해설 영상의 도입부를 시험하는 **22초 분량 제작 예시**다. 질문을 먼저 보여 주고, 화면에서 시청자가 답을 검증하도록 설계했다. 제작팀이 정한 파일 규격·색·시간이며 레퍼런스 채널의 실측값은 채널 분석 문서에서 확인한다. 이 예시의 상태는 **무음 러프컷 검토 대기**다.

[썸네일](thumbnail.png) · [검토용 영상](review.mp4) · [자막](captions.srt) · [재현 코드](render.py)

## 기획 카드

- 대상은 평소 화면 밝기나 사진 보정에 관심 있는 시청자다.
- 제목안은 **두 회색 칸, 어느 쪽이 더 밝을까?** 썸네일에 두 칸을 직접 보여 준다.
- 시청자가 얻을 답은 이 그림의 가운데 두 칸에 같은 픽셀값을 지정했다는 사실이다. 사람마다 느끼는 밝기가 같다고 전제하지 않는다.
- 썸네일 비교 실험에서는 그림의 위치를 고정하고 문구만 ‘어느 쪽이 더 밝을까?’에서 ‘배경을 가리면?’으로 바꾼다. 두 번째 안은 후속 제작 후보이다.
- 롱폼 확장 후보는 명도 대비 실험, 사진 보정에서의 예, 측정값과 체감의 차이 순이다. 시각 지각 원리에 관한 내레이션은 전문 자료를 추가 검토한 뒤 작성한다.

## 타임코드 대본과 편집표

| 구간 | 내레이션 초안·화면 자막 | 샷과 편집 의도 |
|---|---|---|
| 00–05초 | 두 칸 중 어느 쪽이 더 밝아 보이나요? | 화면 왼쪽과 오른쪽에 같은 회색 칸을 올린다. 어두운 바탕과 밝은 바탕이 동시에 보인다. |
| 05–10초 | 가운데 칸만 남겨 볼게요. | 하드 컷으로 바탕만 제거하고 중심 좌표를 유지한다. |
| 10–16초 | 두 칸 모두 RGB 값이 136, 136, 136입니다. | 각각의 칸 바로 아래에 같은 색상 코드를 표시한다. |
| 16–22초 | 같은 회색을 다른 바탕 위에 놓았습니다. | 처음 구도를 다시 보여 주며 시청자가 스스로 확인할 시간을 둔다. |

녹음 시 첫 질문 후 한 박자 쉬고 마지막 문장은 ‘다른 바탕’을 강조한다. 이 무음본에는 검토용 자막이 구워져 있다. 별도 SRT는 대본·타이밍 검토나 자막 없는 마스터를 만드는 후속 작업에 쓴다.

## 자료 원장과 사양

| 자산 | 출처와 검증 | 적용 |
|---|---|---|
| 회색 사각형과 바탕 | `render.py`에서 직접 그림. 좌우 중심 좌표의 RGB 값이 모두 (136,136,136)인지 렌더링 중 검사 | 전체 4개 샷과 썸네일 |
| 제목·내레이션·자막 | 기획팀이 이 실험용으로 작성. SRT와 번인 자막은 같은 타임라인을 사용 | 4문장 |
| 본문 글꼴 | Noto Sans CJK Bold. 설치된 글꼴을 사용하며 폰트 파일은 저장소에 포함하지 않는다. | 크기 40px 자막, 64px 제목 |
| 음성·음악 | 이번 검토 파일은 무음. 녹음 편집자가 승인 대본으로 별도 제작 | 오디오 검수 대기 |

1280×720, 25fps, H.264, 총 22초. 자막은 하단의 짙은 띠 중앙에 흰색 한 줄로 놓았다. RGB 검사는 무손실 작업 이미지에서 수행한다. 인코딩된 영상의 픽셀은 색공간 변환과 압축에 따라 달라질 수 있다.

## 마케팅과 출고 기록

설명란 초안 — “회색 칸 두 개를 보고 어느 쪽이 밝아 보이는지 먼저 골라 보세요. 배경을 걷고 직접 만든 도형의 색 값을 공개합니다.”

고정 댓글 초안 — “처음 고른 쪽과 배경을 가린 뒤의 답이 같았나요?”

검수 담당자는 휴대폰에서 밝기 자동 조정 여부와 함께 답변을 기록한다. 두 중앙 픽셀의 일치, 형태와 위치의 유지, 한글 글리프와 타임코드, 마지막 자막의 끝을 확인한다. 영상은 미게시 상태다. 실제 출고 전 녹음 믹스와 자막 포함·미포함 마스터를 확정한다. 게시 후 같은 길이·유입경로에서 썸네일 클릭률과 정답 공개 전후의 유지율을 비교한다.

## 재생성

Python 3, Pillow, libx264가 포함된 FFmpeg와 한글을 지원하는 글꼴이 필요하다.

```sh
python3 examples/gray-square/render.py --out /tmp/gray-square-preview
ffprobe -v error -show_entries stream=codec_name,width,height,duration /tmp/gray-square-preview/review.mp4
```

다른 OS에서는 `--font`로 설치된 글꼴의 경로를 지정한다. 생성 코드는 빌드 전에 좌우 중심의 색 값을 확인한다.
