# 롱폼 기획안 · 전기를 쓰면 돈을 주는 시간은 왜 생길까?

목표 길이는 15분 내외다. 레퍼런스 장편 6편의 중앙값과, 별도 산업 영상에서 관찰한 통설→반례→분류→단일 사례→반론을 전력시장 주제에 적용한 제안이다. 실제 사례 날짜와 숫자는 자료팀이 확정한다.

|예상 구간|내레이션이 풀 질문|제작할 장면과 확보할 자료|
|---|---|---|
|0:00–0:15|“전기는 쓸 때마다 값을 치릅니다. 그런데 발전소가 전기를 가져가 달라며 돈까지 내는 시간이 있습니다. 그때 우리 집 계량기도 거꾸로 돈을 벌까요?”|검침기 자체 촬영 → 0원 선을 지나가는 자체 그래프 → 가정 요금표. 음수 가격과 가정 요금이 다른 축임을 보여 준다.|
|0:15–2:40|누가 누구에게 얼마를 내는가?|발전사·시장·소매 공급자·가구를 네 칸으로 그린다. 에너지가 가는 방향과 정산금이 가는 방향을 별도 색으로 표시한다.|
|2:40–4:15|기계 가동을 멈추는 편이 언제 더 비싼가?|정지·재가동 비용을 포함한 예시 계산을 만든다. 설명용 가상값에는 화면상 ‘예시’ 라벨을 붙인다.|
|4:15–7:30|선정한 하루에는 실제로 어떤 일이 있었나?|독일 연방네트워크청 SMARD에서 같은 입찰 구역의 도매가격, 발전량, 부하를 같은 시간대로 맞춘다. 공급 초과만으로 인과를 단정하지 않는다.|
|7:30–10:15|저장하거나 다른 곳으로 보내면 되지 않을까?|배터리 잔량과 송전 제약을 독립 도해로 나눈다. 선택한 사례일에 실제 제약이 있었는지는 계통운영자 자료로 검증한다.|
|10:15–13:00|도매가가 내려가면 가정도 돈을 버나?|고정형 요금과 동적 요금 계약 조건을 비교한다. 세금과 망 사용료까지 포함한 소비자 청구액을 별도 계산한다.|
|13:00–15:00|처음 질문에 어떤 조건을 붙여야 정확할까?|첫 장면의 두 축을 다시 겹쳐 보인다. 시장·계약·시간대가 일치하는 경우에만 가구 사례로 연결한다.|

자료팀 출발점은 [독일 전력시장 데이터 SMARD](https://www.smard.de/en)다. 사례 선정 후에는 데이터셋 이름·다운로드 날짜·구간·단위·재사용 조건을 장면별로 기록한다. 일광절약시간과 가격의 MWh→kWh 환산은 독립 검수자가 재계산한다.

썸네일 A는 0원 선 밑으로 내려간 가격표와 계량기를 한 화면에 둔다. B는 동일한 구도에서 가격표 숫자만 질문 부호로 가린다. 제목은 두 안 모두 동일하게 유지한다. 첫 15초의 약속, 노출 경로별 클릭률, 30초 잔존율을 함께 기록한다. 구체적인 음수 가격을 카피에 쓰려면 해당 시장의 실제 관측 날짜와 단위를 먼저 확정한다.

## 인기 영상 분석을 이 회차에 적용한 예

채택한 서사는 `flow`다. 도매가격이 음수가 되는 시간에 돈이 누구에게서 누구에게 가는지 거래 주체별로 따라간다. 비교용 보조 질문은 한국인 평균 편에서 가져온 분모 점검이다. 가구가 실제로 받는 금액과 시장의 MWh당 도매 정산가격을 분리한다.

|팀 인계|제작 결정|검수 자료|
|---|---|---|
|기획 → 대본|첫 질문의 답을 '계약 조건에 따라 달라진다'로 정하고, 실제 사례일을 확보한 뒤 수치를 쓴다.|같은 시간대의 시장 가격·소매 약관·세금의 단위 대조표|
|자료 → 편집|한 화면에서 발전사·거래시장·소매사·가구 네 칸을 유지한다. 물리적 전력과 정산금을 서로 다른 화살표로 표시한다.|각 화살표에 주장 ID와 근거를 붙인 도해 원본|
|마케팅 → 독립 검수|제목에서 가구의 실제 수익을 단정하면 반송한다. 중간에 든 예외적 계약이 썸네일에서 전체 가구처럼 보이는지도 확인한다.|도입 질문이 회수되는 장면과 출고 제목을 짝지은 검수 기록|
|출고 → 회고|유입 경로와 게시 후 경과 시간을 맞춘 뒤, 가격 그래프에서 계약 설명으로 넘어가는 구간의 이탈을 기록한다.|실제 채널 지표 확보 전까지 실험 결과는 미측정|
