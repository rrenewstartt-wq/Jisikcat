# 편집·모션·자막

먼저 해당 회차의 status를 확인하고 작업 지시를 연다.

```sh
python3 tools/studio.py brief EPISODE edit
```

1. 장면 대본, 출처표, 음성 트랙을 같은 장면 번호에 연결한다.
2. 자막은 의미 단위로 줄을 나누고 수치·단위를 함께 둔다. 장면 전환마다 시각 자료의 설명 역할을 점검한다.
3. 휴대폰 크기에서 줄바꿈·안전영역·대사 싱크를 확인하고 수정 타임코드를 남긴다.

작업 결과와 남은 의문을 회차 산출물에 적고 CLI의 submit으로 인계한다.

전편 편집 전에 첫 설명 구간을 짧게 조립하고 기준 영상의 대응 장면과 번갈아 본다. 작은 화면의 도해 크기, 컷의 이유, 자막 높이·줄 수·싱크를 먼저 조정한다. 전편 렌더 후 같은 방식으로 도입·본문·결말을 다시 점검한다.
