# 편집·모션·자막

먼저 해당 회차의 status를 확인하고 작업 지시를 연다.

```sh
python3 tools/studio.py brief EPISODE edit
```

1. 장면 대본, 출처표, 음성 트랙을 같은 장면 번호에 연결한다.
2. 자막은 의미 단위로 줄을 나누고 수치·단위를 함께 둔다. 장면 전환마다 시각 자료의 설명 역할을 점검한다.
3. 휴대폰 크기에서 줄바꿈·안전영역·대사 싱크를 확인하고 수정 타임코드를 남긴다.

작업 결과와 남은 의문을 회차 산출물에 적고 CLI의 submit으로 인계한다.

전편 편집 전에 첫 설명 구간을 짧게 조립하고 기준 영상의 대응 장면과 번갈아 본다. 작은 화면의 도해 크기, 컷의 이유, 자막 높이·줄 수·싱크를 먼저 조정한다. 전편 렌더 후 같은 방식으로 도입·본문·결말을 다시 점검한다.

## 담당자의 결정과 인수 검사

편집감독이 각 컷의 진입·이탈 시점과 화면에서 읽을 정보의 우선순위를 결정한다.

- **인계 기록.** master.mp4와 captions.srt에 같은 주장·장면 순서를 사용한다. 근거가 등장할 때 음성과 도해가 같은 수치·대상을 가리키는지 대조하고 결말에서 질문을 회수한 실제 시각을 마케팅에 넘긴다.
- **실제 검사.** 무음으로 자막과 도해를 본 뒤 화면 없이 대사를 듣는다. 양쪽이 서로 다른 결론을 주는 곳, 축·단위가 가리는 곳, 마지막 자막이나 음성이 잘리는 곳을 회차 타임코드로 표시한다.
- **수정 경로.** 축·단위 오류는 자료팀, 테이크 오류는 음향팀, 인과가 달라진 컷은 대본팀과 수정한다. 변경된 마스터·SRT 쌍에 대해 대조 심사를 갱신한다.

## 화면이 카드 설명으로 반복될 때

- 대본에서 **실제로 볼 수 있는 동작**, **숫자가 변하는 순간**, **거래 주체가 바뀌는 순간**의 시각을 먼저 표시한다. 동작에는 출처가 확인된 촬영본을, 수치에는 그 발화에 맞춰 값이 바뀌는 도해를 배치한다.
- 컷 목록에 편집본 시각, 원본 시작점, 촬영자와 자료화면 용도를 남긴다. 차트는 축·단위와 교차 시점, 영수증은 항목·합계가 보이는 시점을 완성 파일에서 검토한다.
- 검정·정지 감지 통과만으로 시각 연출을 승인하지 않는다. 무음으로 도입·본문·결말을 보고 피사체, 동작, 수치 변화 중 무엇이 대사를 전달했는지 적는다. [실사·모션 편집 예](../../../episodes/ep-001-power/edit/motion/README.md)

자막 한 줄에 종결어미만 남거나 부호가 금액과 갈리면 녹음의 쉼을 찾아 앞뒤 발화를 나눈다. 분할한 자막을 테이크별로 이어 원고와 대조하고, 가장 긴 문구는 실제 글꼴로 렌더해 휴대폰 폭에서 읽는다. 통계 도해·실사·영수증처럼 배경 성격이 다른 장면에서 출처와 단위가 가려지는지도 확인한다. [EP-001의 재현 가능한 검사](../../../episodes/ep-001-power/qa/check_captions.py)
