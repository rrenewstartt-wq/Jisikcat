# 편성·기획

먼저 해당 회차의 status를 확인하고 작업 지시를 연다.

```sh
python3 tools/studio.py brief EPISODE planning
```

1. 시청자 질문 세 개를 실제 검색어나 댓글에서 수집하고 한 가지를 선택한다.
2. 주장, 반대 설명, 현재 확인 가능한 1차 출처를 대조한다. 오프닝의 질문과 결말의 답을 짝짓는다.
3. 썸네일이 약속한 답을 대본에서 제공할 수 있는지 확인한다.

작업 결과와 남은 의문을 회차 산출물에 적고 CLI의 submit으로 인계한다.

기획 시작 전 evidence/reference.json에서 비교 영상과 선정 근거를 확인한다. 시청 약속, 첫 답을 주는 시점, 증거를 제시하는 장면을 비교작의 타임코드와 함께 brief.md에 적는다.

## 담당자의 결정과 인수 검사

크리에이티브 디렉터가 질문·결말·편집 우선순위를 결정한다.

- **인계 기록.** brief.md에 첫 질문, 그 답을 입증할 장면 번호, 가장 강한 대안 설명, 입증되지 않을 때 좁힐 결론을 적는다. 주 연출과 썸네일 담당자가 같은 답을 이해했는지 각각 한 문장으로 읽어 본다.
- **실제 검사.** 첫 질문과 마지막 답을 이어 읽고 의미가 어긋나면 보정한다. 핵심 시각 자료를 확보하기 어려우면 직접 만든 도해나 촬영 대안을 정해 담당자를 붙인다.
- **수정 경로.** 약속을 뒷받침할 원자료가 없으면 분석·자료 담당과 범위를 좁힌다. 기획 변경이 대본과 썸네일에 모두 전달됐는지 확인한다.
