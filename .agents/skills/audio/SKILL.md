# 내레이션·사운드

먼저 해당 회차의 status를 확인하고 작업 지시를 연다.

```sh
python3 tools/studio.py brief EPISODE audio
```

1. 확정 대본에서 고유명사 발음과 강조 지점을 표시한다.
2. 대사·배경음·효과음을 별도 트랙으로 납품하고 파일별 사용권을 적는다.
3. 휴대폰 스피커로 대사 명료도, 치찰음, 음원 전환과 클리핑을 점검한다.

작업 결과와 남은 의문을 회차 산출물에 적고 CLI의 submit으로 인계한다.

기준 영상의 도입, 수치 설명, 음악이 있는 구간을 같은 재생 음량으로 번갈아 듣는다. 발음 명료도, 문장 사이 쉼, 효과음이 대사를 덮는 위치를 테이크별로 수정한다.

## 담당자의 결정과 인수 검사

목소리만으로 숫자의 단위·비교 대상·강조어가 들리도록 연출한다.

- **인계 기록.** narration.wav와 장면별 테이크 위치를 연결한다. 수치가 촘촘한 문장에 호흡 자리를 정하고 수정한 테이크의 앞뒤 발음·잔향도 이어 듣는다.
- **실제 검사.** 대본을 가린 동료가 핵심 수치 한 문장을 받아 적게 한다. 원자료의 분모와 단위가 들렸는지 대조하고 실제 클리핑, 잡음, 효과음과의 겹침을 재생 시각과 함께 남긴다.
- **수정 경로.** 입 모양·발음·말속도는 재녹음한다. 의미가 모호한 문장은 대본으로 돌리고, 마스터에서만 가려지는 음성은 편집 믹스에서 바로잡는다.
