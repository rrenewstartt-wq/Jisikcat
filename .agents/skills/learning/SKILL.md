# 성과 분석·회고

먼저 해당 회차의 status를 확인하고 작업 지시를 연다.

```sh
python3 tools/studio.py brief EPISODE learning
```

1. 같은 업로드 경과 시간과 비슷한 길이·유입경로의 영상끼리 비교한다.
2. 측정 날짜, 노출수, CTR, 평균 시청 시간, 이탈 구간을 기록하고 가능한 다른 설명을 적는다.
3. 다음 회차에서 검증할 변화 하나와 성공 기준을 기획팀에 전달한다.

작업 결과와 남은 의문을 회차 산출물에 적고 CLI의 submit으로 인계한다.

## 담당자의 결정과 인수 검사

한 번의 관측에서 다음 회차의 편집 결정을 한 가지 도출한다.

- **인계 기록.** retrospective.md에 영상 길이, 공개 경과 시간, 표본 수, 유입 경로와 관측한 분모를 쓴다. 첫 질문·첫 증거·결말 회수 시각을 실제 유지율 구간에 맞춰 둔다.
- **실제 검사.** 노출수와 조회수를 나눠 CTR 분모를 확인한다. 업데이트·제목 변경·외부 유입 시점을 겹쳐 보고 가능한 다른 설명을 적는다. 미공개 수치는 미측정으로 둔다.
- **수정 경로.** 자료가 적으면 재측정 시점과 자료 소유자를 남긴다. 판단 가능한 경우에는 다음 회차에서 바꿀 요소 하나와 유지할 비교 조건을 기획에 전달한다.
