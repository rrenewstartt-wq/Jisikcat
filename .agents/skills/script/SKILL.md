# 집필·팩트체크

먼저 해당 회차의 status를 확인하고 작업 지시를 연다.

```sh
python3 tools/studio.py brief EPISODE script
```

1. 기획의 핵심 질문과 가용 증거부터 읽는다.
2. 장면별로 발화, 화면, 출처 ID를 적고 추정과 사실을 문장 안에서 구분한다.
3. 소리 내어 읽은 시간으로 구간을 조정하고 단위·숫자·인용 원문을 확인한다.

작업 결과와 남은 의문을 회차 산출물에 적고 CLI의 submit으로 인계한다.
