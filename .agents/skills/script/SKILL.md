# 집필·팩트체크

먼저 해당 회차의 status를 확인하고 작업 지시를 연다.

```sh
python3 tools/studio.py brief EPISODE script
```

1. 기획의 핵심 질문과 가용 증거부터 읽는다.
2. 장면별로 발화, 화면, 출처 ID를 적고 추정과 사실을 문장 안에서 구분한다.
3. 소리 내어 읽은 시간으로 구간을 조정하고 단위·숫자·인용 원문을 확인한다.

작업 결과와 남은 의문을 회차 산출물에 적고 CLI의 submit으로 인계한다.

대본 작성 전 기준 영상의 첫 질문, 첫 증거, 중간 답, 반론, 마지막 회수를 타임코드로 표시한다. 이번 주제의 대응 문장과 근거를 나란히 놓고 낭독한다. 대응이 끊기는 구간은 집필 단계에서 다시 구성한다.

## 담당자의 결정과 인수 검사

독자가 들은 문장만으로 사실·추정·주어진 조건을 구별할 수 있게 쓴다.

- **인계 기록.** script.md의 장면별 핵심 주장에 C01 같은 번호를 달고 facts.md에 원문 제목·표/절·기간·분모·계산을 연결한다. 반대 편집자가 해당 자료로 만들 수 있는 가장 강한 반론을 한 번 적는다.
- **실제 검사.** 반올림 전 값을 이용해 비율을 재계산한다. 시점이 다른 수치를 나란히 보여 줄 때 기저·가격 기준·분모가 같은지 확인한다. 마지막 문장이 첫 질문에 실제 답하는지 낭독한다.
- **수정 경로.** 반론이 성립하면 문장 범위를 줄이고 기획·썸네일에도 반영한다. 승인 뒤 바뀐 숫자와 읽는 법은 음향·편집에 함께 전달한다.
