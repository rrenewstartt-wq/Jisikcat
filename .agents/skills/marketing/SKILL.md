# 마케팅·배포 기획

먼저 해당 회차의 status를 확인하고 작업 지시를 연다.

```sh
python3 tools/studio.py brief EPISODE marketing
```

1. 시청 약속에 맞는 제목, 설명, 챕터, 크레디트를 작성한다.
2. 가설마다 비교 기간, 유입 경로, 판단 지표와 변경 요소 하나를 기록한다.
3. CTR·유지율은 실제 소유자 데이터가 들어올 때까지 미측정으로 둔다.

작업 결과와 남은 의문을 회차 산출물에 적고 CLI의 submit으로 인계한다.

기준작과 제작본의 제목·썸네일을 한 쌍씩 놓고 시청자가 기대할 답을 한 문장으로 적는다. 제작본의 실제 회수 시점을 대조팀에 인계한다.

## 담당자의 결정과 인수 검사

설명·표지·제목을 보고 한 기대가 실제 영상에서 회수되도록 한다.

- **인계 기록.** metadata.md에 시청자가 얻을 답과 실제 회수 장면, 제목·썸네일 최종 조합, 출처·크레디트를 적는다. 엔딩에서만 밝히는 조건이 제목에 필요한지 판단한다.
- **실제 검사.** 두 패키지를 시험할 때는 제목·표지 중 바뀌는 한 요소와 게시 후 비교 창을 정한다. 동시 실험·무작위 배정 여부를 적고 순차 변경의 유입 차이를 기록한다.
- **수정 경로.** 누락된 자격·기간·단위를 제목 또는 표지에 복구한다. 약속 변경은 기획, 이미지 변경은 썸네일, 회수 장면 변경은 편집으로 돌린다.
