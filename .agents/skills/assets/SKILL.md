# 자료 조사·권리

먼저 해당 회차의 status를 확인하고 작업 지시를 연다.

```sh
python3 tools/studio.py brief EPISODE assets
```

1. 장면별로 설명에 필요한 정보와 시각 기능을 명시한다.
2. 자료별 원문 URL, 제작자, 사용 조건, 확인일, 편집 범위, 크레디트를 기록한다.
3. 권리 불명 자료는 원자료 기반 자체 도해 또는 직접 촬영으로 교체한다.

작업 결과와 남은 의문을 회차 산출물에 적고 CLI의 submit으로 인계한다.

기준 영상에서 증거를 보여 주는 장면과 단순 분위기 컷을 구분한다. 각 주장에 대응하는 자체 원자료·도해·자료화면을 확보해 편집팀에 넘긴다.

## 담당자의 결정과 인수 검사

시청자가 자료 한 컷을 보고 어떤 사실을 검증할 수 있는지 설명한다.

- **인계 기록.** sources.json의 asset/source/license/evidence/credit에 샷과 주장 연결, 원본 위치·취득일·사용조건을 기록한다. 도해에는 원표의 단위·기간을 옮기고 발췌·축약 범위를 표시한다.
- **실제 검사.** 파일을 실제로 열어 지역·연도·사건 주체가 대본과 맞는지 본다. 자료화면이나 재연은 화면 표시를 결정한다. 음악과 사진의 공개·가공 가능 여부를 각 자산별로 확인한다.
- **수정 경로.** 주장을 입증하지 못하는 컷은 대본팀에 알리고 실제 증거를 찾는다. 이용 조건이 불분명하면 자체 도해·촬영으로 교체하고 편집 출처표를 갱신한다.
