# 자료 조사·권리

먼저 해당 회차의 status를 확인하고 작업 지시를 연다.

```sh
python3 tools/studio.py brief EPISODE assets
```

1. 장면별로 설명에 필요한 정보와 시각 기능을 명시한다.
2. 자료별 원문 URL, 제작자, 사용 조건, 확인일, 편집 범위, 크레디트를 기록한다.
3. 권리 불명 자료는 원자료 기반 자체 도해 또는 직접 촬영으로 교체한다.

작업 결과와 남은 의문을 회차 산출물에 적고 CLI의 submit으로 인계한다.

기준 영상에서 증거를 보여 주는 장면과 단순 분위기 컷을 구분한다. 각 주장에 대응하는 자체 원자료·도해·자료화면을 확보해 편집팀에 넘긴다.
