# 썸네일·패키징

먼저 해당 회차의 status를 확인하고 작업 지시를 연다.

```sh
python3 tools/studio.py brief EPISODE thumbnail
```

1. 한 화면에서 전달할 질문, 주 피사체, 대비 관계를 먼저 정한다.
2. 제목과 썸네일을 한 쌍으로 설계하고 가설 하나만 달리한 두 시안을 만든다.
3. 축소 미리보기에서 핵심 피사체와 카피를 판독하고 영상 내용과 대조한다.

작업 결과와 남은 의문을 회차 산출물에 적고 CLI의 submit으로 인계한다.

reference.jpg와 두 시안을 같은 모바일 폭으로 축소한다. 주 피사체·첫 시선·제목과 겹치는 정보·우하단 가림을 비교해 최종 JPG를 선정한다.

## 담당자의 결정과 인수 검사

아트디렉터가 작은 화면에서 피사체와 시청 약속이 함께 읽히는 구도를 선택한다.

- **인계 기록.** thumbnail.jpg 후보를 동일한 작은 폭에 나란히 놓고 제목을 가린다. 동료가 어떤 사물·질문을 읽는지 물어 실제 답을 적는다. 동일 제목에서 시험할 단일 변수와 선택 이유를 남긴다.
- **실제 검사.** 우하단 재생시간 표식 자리를 가려 본 뒤 핵심 숫자와 단위가 남는지 확인한다. 제목과 표지가 합쳐져 대본에 없는 인과·금액·일반화를 암시하는지도 본다.
- **수정 경로.** 피사체 오인·안전영역 문제는 디자이너가 수정한다. 작품의 약속 자체가 달라지면 기획·마케팅과 도입부까지 재검토한다.
