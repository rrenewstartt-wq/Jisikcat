# 레퍼런스 분석

먼저 해당 회차의 status를 확인하고 작업 지시를 연다.

```sh
python3 tools/studio.py brief EPISODE analysis
```

1. 채널 ID를 대조하고 기간·선정 기준을 먼저 적는다. 조회수 순위와 최신 표본을 분리한다.
2. 각 측정에 영상 URL, 관찰 날짜, 구간, 측정 단위를 붙인다. 반복 횟수를 분모와 함께 적는다.
3. 원출처 미상, 글꼴 추정, 실측 불가 항목을 분리한다.

작업 결과와 남은 의문을 회차 산출물에 적고 CLI의 submit으로 인계한다.

## 담당자의 결정과 인수 검사

편집에 도움이 되는 비교 표본을 고르고 관찰과 가설의 경계를 지킨다.

- **인계 기록.** observations.md에 표본의 게시일·형식·선정 이유·분자/분모를 적는다. 같은 소재라도 쇼츠와 장편의 속도를 따로 계산하고 반례 한 편을 찾아 기록한다. story_formula를 쓸 때는 근거의 위치와 이번 회차에서 바꿀 요소를 쓴다.
- **실제 검사.** 기준물 확보자가 URL과 시각으로 같은 현상을 다시 찾을 수 있는지 확인한다. 제목이나 2차 요약에서 추론한 장면은 촬영·편집 관찰로 승격시키지 않는다.
- **수정 경로.** 다른 채널·버전·단위가 섞이면 분석팀이 표본과 그에 의존한 빈도를 다시 계산한다.
