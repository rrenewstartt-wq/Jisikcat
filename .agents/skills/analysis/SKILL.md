# 레퍼런스 분석

먼저 해당 회차의 status를 확인하고 작업 지시를 연다.

```sh
python3 tools/studio.py brief EPISODE analysis
```

1. 채널 ID를 대조하고 기간·선정 기준을 먼저 적는다. 조회수 순위와 최신 표본을 분리한다.
2. 각 측정에 영상 URL, 관찰 날짜, 구간, 측정 단위를 붙인다. 반복 횟수를 분모와 함께 적는다.
3. 원출처 미상, 글꼴 추정, 실측 불가 항목을 분리한다.

작업 결과와 남은 의문을 회차 산출물에 적고 CLI의 submit으로 인계한다.
