# 제작 핸드북

한 회차가 끝날 때 같은 프레임을 다시 만들 수 있도록, 분석 기록에서 출고 파일까지 근거와 버전을 이어 간다. 팀 이름과 제출 순서는 `python3 tools/studio.py teams`에서 확인한다. 아래 표는 사람이 수행할 작업과 인수 조건이다.

| 팀 | 실제 작업 | 다음 팀이 인수할 때 확인할 것 |
|---|---|---|
| 분석 | 최근 영상과 인기 영상의 겹침을 제거하고 쇼츠·롱폼을 나눈다. 제목의 질문 형태, 첫 화면과 썸네일의 연결, 답을 제시하는 시점, 자막과 내레이션의 관계를 시각 코드와 타임코드로 기록한다. | 영상 ID, 샘플 수, 관찰 구간, 반례, 미확인 항목이 적힌 관찰표 |
| 기준물 확보 | 분석팀이 고른 영상의 실제 영상·자막·썸네일을 확보하고 각각의 출처와 선정 이유를 기록한다. | 같은 버전에 대한 증거 파일을 열 수 있고 자막의 시간축이 영상과 일치 |
| 기획 | 관찰한 패턴 하나를 골라 새 주제에 적용한다. 시청자 질문 한 문장, 검증 가능한 답 한 문장, 이탈할 이유와 대응 장면 하나를 정한다. | 제목의 약속을 입증하는 장면이 기획안 안에 있음 |
| 대본·팩트체크 | 각 문장을 화면으로 표현할 수 있는 단위로 분할한다. 핵심 주장의 근거에 식별자를 붙인다. 반례가 있으면 해당 문장을 조건부로 고친다. 소리 내 읽고 긴 문장을 나눈다. | 주장→출처→샷 번호가 연결되고 읽기 시간이 편집표에 들어감 |
| 자료 | 자체 촬영, 직접 만든 도해, 이용 조건을 확인한 외부 자료 중 하나를 각 샷에 지정한다. 외부 자료는 원본 파일명, 저작자, 개별 파일 URL, 사용 조건, 확인일, 표기 문구를 함께 보관한다. | 자산별 실제 파일과 이용 근거가 모두 열림. 출처 추정은 후보로만 저장 |
| 썸네일 | 무음·작은 화면에서 제목을 가린 채 질문이 읽히는지 본다. 한 가지 가설을 정하고 구도·문구·피사체 크기 중 한 요소만 바꾼 비교안을 만든다. | 모바일 축소본과 실제 첫 화면에서 같은 피사체·약속이 이어짐 |
| 오디오 | 문장 단위로 녹음하고 강조어 앞뒤에 숨 쉴 공간을 둔다. 배경음 사용 시 같은 구간을 휴대폰 스피커로 재생해 말끝이 묻히는지 확인한다. | 승인된 대본 버전과 음성 파일이 일치하고 수정한 테이크 위치가 남음 |
| 편집·자막 | 음성에 샷을 붙이고 정보가 바뀌는 순간에 컷을 건다. 자막은 의미 단위로 줄바꿈한다. 수치나 고유명사 주변에서는 줄을 유지한다. 첫 화면·중간·마지막에서 자막과 도해의 겹침을 본다. | 타임코드가 있는 자막, 편집표, 검토용 인코딩, 최종 프레임에서 자막 확인 |
| 마케팅 | 제목·썸네일 조합이 똑같은 사실을 약속하는지 본다. 설명, 자산 크레디트, 고정 댓글 초안을 준비한다. 비교 실험은 변경 항목과 관찰 기간을 미리 기록한다. | 패키징 안마다 가설 하나와 측정 방법 하나가 남음 |
| 레퍼런스 대조 | 기준물과 편집본·마케팅 패키지에서 같은 역할을 하는 구간을 찾는다. 일곱 비교 항목에 양쪽 시각과 확인 결과를 남긴다. | 결함을 수정한 버전에서 모든 항목의 근거를 재현할 수 있음 |
| 독립 검수 | 사실·권리·기술을 각각 다시 확인한다. 시간 코드, 재현 방법, 예상 결과를 붙여 문제를 담당 팀에 돌려보낸다. 수정본에서 같은 구간을 다시 확인한다. | 누가 무엇을 재검사했는지, 열린 문제가 무엇인지 알 수 있음 |
| 출고 | 파일명, 러닝타임, 해상도, 오디오 트랙, 자막, 썸네일, 설명란의 출처를 묶는다. 공개 여부는 실제 배포 담당자가 확정한다. | 승인한 버전의 해시와 실제 게시물 ID 또는 대기 상태가 일치 |
| 학습 | 같은 형식·길이·유입 경로의 기준 영상과 비교한다. 롱폼은 노출 클릭률과 첫 30초 유지율, 쇼츠는 시청 선택과 평균 시청 비율을 우선 본다. 지표 정의, 관측창과 표본 크기를 남긴다. | 다음 회차에서 바꿀 변수 하나가 정해짐. 집계 전에는 결과를 빈 값으로 둠 |

## 레퍼런스를 제작 지시서로 바꾸기

영상별로 `video_id / 시작–끝 / 관찰 / 측정법 / 샘플 범위 / 우리 회차의 구현`을 한 줄에 적는다. 예를 들어 글꼴은 글자 윤곽, 획 굵기, 색, 그림자, 화면 대비 높이를 기록하고, 실제 글꼴 이름은 제작자가 밝힌 경우에만 기입한다. 출처가 명시된 장면도 같은 소스를 쓸 수 있는지는 별도 확인한다.

색·좌표는 원본 화면 크기와 함께 측정한다. 캡션 높이는 프레임 높이 대비 비율, 좌우 정렬은 프레임 폭 대비 좌표로 보관하면 다른 해상도에서 재현하기 쉽다. 쇼츠의 오른쪽 버튼과 하단 설명이 실제 텍스트를 가리는지는 모바일 미리보기에서 확인한다.

장면 전환 간격은 관찰 구간의 컷 사이 시간, 자막 체류 시간은 자막 한 단위가 보이는 시간으로 잰다. 중앙값에는 표본 수를 함께 적는다. 도입과 본론의 값은 따로 보관한다. 지시서에는 근거가 확인된 설정과 이번 편에서 시험할 설정을 구별해 적는다.
