# 다섯 사례를 회차에 적용하기

[사례별 근거와 관찰 범위](../benchmark/top5-stories.md)를 읽고 주제에 맞는 질문 한 가지를 고른다. 사례 이름은 설계 방식을 찾기 위한 색인이다. 분석팀은 원본에서 관찰한 내용과 이번 회차에 쓰기로 한 표현을 observations.md에서 구분한다.

|분석 인계 값|사례|새 영상에서 확인할 것|
|---|---|---|
|average|한국인 평균|통념의 근거가 된 수치의 분모·기간·분포|
|field|몽골|관찰한 장소와 조건, 다른 지역으로 일반화할 수 있는 범위|
|aftermath|러시아|사건 전후의 변화, 대가를 치른 주체, 다른 가능한 원인|
|flow|석유복지|재원에서 수혜자까지 각 단계의 자격·배분 조건|
|chain|리먼|위기가 전파되는 인과 고리와 각 고리의 증거|
|custom|자체 설계|이번 편의 독자 질문과 판단 근거|

분석팀은 기존 질문과 답을 유지하면서 analysis/handoff.json에 선택적으로 `"story_formula": "flow"`와 같이 키 하나를 추가한다. 선택 근거는 observations.md에 적는다. 신규·기존 회차에서 추가 설정 없이 `python3 tools/studio.py brief ep-001 script`를 실행하면 선택한 질문, 검증 단서, 해당 팀의 작업과 인계 전 점검 항목이 나온다. `python3 tools/dispatch.py ep-001 script`로 배정해도 같은 지침을 받는다. 기존 회차에 선택 값이 없으면 다섯 후보가 표시되며 기존 산출물을 수정할 필요가 없다. 분석 제출 뒤 선택을 변경하면 기존의 파일 변경 감지·재검토 절차가 적용된다.

예를 들어 flow 회차에서 자료팀은 '재원 → 중간 기관 → 조건 → 수혜자'를 뒷받침할 자료와 사용권을 sources.json에 기록한다. 편집팀은 각 주체의 등장이 해당 발화·자막과 일치하는지 확인한다. 독립 검수팀은 제목에서 전체 국민의 혜택처럼 읽히는 표현이 실제 자격 조건을 생략했는지 확인한다. 원본의 특정 컷, 자막 문구, 시간값은 근거가 확인된 범위에서만 기록한다.

## 시안 제작과 관측 계획

아래는 새 회차에서 시험할 작업이다. 성공 여부는 자체 채널의 같은 경과 시간·유입 경로·영상 길이를 기준으로 비교한다.

|채택한 설계|첫 시안에서 바꿀 요소|검수팀이 확인할 실패 조건|회고할 위치|
|---|---|---|---|
|average|동일한 급여를 전체 평균과 같은 연령대 중앙값으로 두 번 표시한다.|숫자 옆 연도나 분모가 사라지면 비교를 다시 편집한다.|두 번째 기준이 처음 드러나는 시점의 이탈과 댓글의 분모 질문|
|field|현지 상점 간판을 보여 준 뒤 같은 위치를 좁은 지도에서 넓은 지도로 확장한다.|한 점포의 모습으로 국가 전체의 소비 습관을 단정하면 근거를 추가한다.|장소 공개 전후의 이탈과 지역 관련 정정|
|aftermath|같은 품목을 생산자 가격·소비자 가격에서 각각 한 번 보여 준다.|두 시점의 통화·물량·단위가 맞지 않거나 대체 원인을 누락하면 반송한다.|거시 지표에서 생활 사례로 돌아오는 장면의 잔존율|
|flow|같은 색으로 하나의 수입이 예산과 지급을 거쳐 이동하는 흐름을 그린다.|국가 총수입을 개인 지급액으로 바꾸는 중간 단계가 비면 집필팀으로 돌린다.|자격 조건이 나오는 시각과 대상자를 혼동한 댓글|
|chain|같은 계약을 놓고 주체가 바뀔 때만 화살표를 추가한다.|금융 용어를 몰라도 손실 부담자를 따라갈 수 있는지 검수자가 설명한다.|첫 계약 도해부터 손실 회수까지의 이탈·재시청|

러시아 편에는 경제 근황을 묻던 제목을 전쟁의 대가에 초점을 맞춘 제목으로 바꾼 기록이 있고, 리먼 편에는 자극적 표현을 덜고 쉬운 설명을 약속하는 쪽으로 고친 기록이 있다. 마케팅팀은 변경 전후 제목, 적용 시각, 교체한 썸네일, 유입 경로와 노출수를 함께 남긴다. 두 변경 사례에서 조회수 상승의 원인은 확인되지 않았다. ## 과거 고조회수 영상에서 추가로 가져올 수 있는 포장 방식

AskNaveen에 남은 인도 빈부 격차, 파텍필립, 롤스로이스 편은 위 vidIQ 표보다 높은 누적 조회수를 기록한 사례다. 같은 시점의 전체 채널 전수 목록을 확보하기 어려워 별도 비교 대상으로 둔다. 이들의 제목만으로 확인할 수 있는 공통점은 낯선 규모를 익숙한 기준으로 환산한다는 것이다. 인도 편은 같은 나라에서 대비되는 두 집단, 파텍필립 편은 익숙한 비교 브랜드, 롤스로이스 편은 주택 수로 바꾼 가격을 제시한다. 한국인 평균 편은 이 기준 자체가 타당한지를 되묻는다. [보존된 채널 기록](https://asknaveen.com/channel/@지식한입)

주제에 적합하면 기획팀이 비교 대상을 하나 제안하고, 자료팀이 두 값의 기준일·통화·표본이 맞는지 확인한다. 썸네일팀은 같은 화면에 두 대상을 배치하고, QA는 예외적으로 비싼 한 대의 가격을 전체 차종의 가격처럼 표시했는지 확인한다. 정용진 편과 같은 인물형 제목은 공적 의사결정과 개인의 동기를 구분해 검수한다. 가격 환산·대비·인물 질문은 제목에서 뽑은 제작 아이디어다.

포맷 분석팀은 채택한 사례에서 서사 기능과 실제 컷·자막·소리가 함께 드러나는 세 지점을 기록한다. 화면 근거 검수팀은 각 주장의 제작본 시각을 해당 기능을 가진 기준 장면에 연결해 두 화면을 대조한다. [파일 규격과 비교 프레임 추출](SCENE-EVIDENCE.md)
