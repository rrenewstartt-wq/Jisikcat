# 회차 검수에서 시간축 결함 찾기

비교팀이 `comparison`을 제출하면 기준물과 제작본의 MP4·SRT를 각각 읽는다. 잘못된 자막 시각은 파일명·행 번호·문제 구간을 표시한다. FFmpeg가 검출한 검정 화면·정지 화면·무음은 각각 최장 지속시간과 누적시간을 초 단위로 보고한다. 기존 메트릭 18개에 이 6개가 추가된다. 모든 메트릭은 동일한 출고 심사에서 평가된다.

## 승인과 반려 조건

|검사|검출 조건|기준물 대비 허용량|
|---|---|---|
|검정 화면|픽셀 98% 이상이 검정 임계값(휘도 범위의 5%) 아래인 상태가 1초 이상 지속|최장 구간은 기준값에서 1.5초 또는 25% 중 큰 값만큼 증가 가능. 누적 시간의 여유는 3초 또는 제작본의 2% 중 큰 값|
|정지 화면|가로 최대 320픽셀로 축소한 프레임에서 FFmpeg가 −50dB 변화 임계값으로 3초 이상 정지를 검출|최장 구간 여유 6초 또는 기준값의 35%. 누적 여유 15초 또는 제작본의 10%. 각각 큰 값 적용|
|무음|첫 오디오 스트림이 −55dB 이하로 1.5초 이상 지속. 오디오가 영상보다 일찍 끝나면 끝까지 무음으로 계측|최장 구간 여유 2.5초 또는 기준값의 35%. 누적 여유 5초 또는 제작본의 5%. 각각 큰 값 적용|
|자막 타임라인|각 큐의 시작이 영상 안에 있고 시간순이며 종료가 시작보다 뒤에 위치|영상 끝에서 100ms까지 멀티플렉싱 오차 허용. 화자 교차나 이중 자막의 시간 중첩 허용|

누적시간은 기준 영상이 차지하는 비율을 제작본 길이에 맞춰 환산한 다음 여유를 더한다. 예를 들어 기준 영상 100초 중 10초가 무음이고 제작본이 110초라면 누적 무음 상한은 11초 + 5.5초다. 세 검출기의 결과는 같은 구간에 겹칠 수 있으므로 서로 합산하지 않는다. 검출기와 여유 값은 작업실의 초기 운영값이며 기준 채널에서 통계적으로 추출한 수치가 아니다.

## 실제 인코딩 파일을 이용한 회귀 검사

저장소 루트에서 실행한다.

```sh
python3 -m unittest discover -s tests -p 'test_temporal.py' -v
```

- 12초 MP4의 1–2초 큐를 13–14초로 옮기면 기존 자막 수·노출 중앙값·줄 수·글자 수가 모두 같다. 새 타임라인 검사는 이 큐가 영상 밖에서 시작해 재생 중 한 번도 표시될 수 없음을 찾아낸다.
- 같은 MP4에서 7초 이후의 오디오 패킷을 없애도 기존 통합 음량 차이는 2 LUFS 이내다. 시간축 검사는 누락된 꼬리 구간 약 5초를 찾아낸다.
- 4초부터 영상 끝까지 화면을 검게 덮으면 블랙아웃과 정지 장면의 최장 시간이 반려 근거에 표시된다. 동일한 정지 구간이 기준물에도 있으면 통과한다.
- 정상 대화의 1초 휴지와 두 화자의 자막이 0.1초 겹치는 샘플은 통과한다.

이 검사는 프레임 밝기·변화량과 오디오 레벨을 측정한다. 검정 화면에 로고가 크게 들어 있거나 정지 화면에 움직이는 오버레이가 있으면 검출이 어려울 수 있다. 두 파일에 비슷한 길이의 결함이 있거나 각 구간의 배치만 달라진 경우도 시간 총량만으로 가려낼 수 없다. 의미 있는 연출인지 판단할 때는 해당 장면과 해설을 함께 재생한다.
