# 장면별 자료 조달

레퍼런스 제작자가 실제로 구매하거나 다운로드한 원본은 영상 설명의 명시적 크레디트 또는 제작자 공개 자료로 확인한다. 아래 표는 Jisikcat이 같은 설명 기능을 자체 제작하는 경로다.

|장면이 해야 하는 일|첫 탐색 경로|편집 인계물|검수에서 자주 발견할 문제|
|---|---|---|---|
|두 시점의 산업 규모 비교|[국가통계포털](https://kosis.kr/), 기업의 분기 실적·감사보고서|표 ID·시점·단위와 직접 그린 선그래프|실질·명목, 누계·분기, 매출·영업이익 혼용|
|공시·정책의 특정 문구 제시|[DART](https://dart.fss.or.kr/), 발행기관 원문|문서명, 발행일, 페이지, 해당 문장과 필요한 주변 맥락|개정 전 문구, 자회사 수치를 그룹 전체로 확장|
|사건 당시의 장소·공간 설명|직접 촬영, 명시적 사용 허가 자료, [Wikimedia Commons](https://commons.wikimedia.org/)의 개별 파일|촬영일과 자료일, 저작자, 파일별 조건, 크롭·색보정 여부|동명이인·다른 장소, 자료화면을 실제 현장처럼 제시|
|인과 관계와 돈의 흐름 설명|검증한 자료로 자체 벡터 도해 제작|편집 가능한 원본, 단위·화살표 의미, 주장 ID|돈과 상품의 방향 혼동, 추정 관계를 확정적으로 그림|
|기사·인터뷰에 나온 증언|인터뷰 원문·원영상 또는 정식 라이선스|화자, 날짜, 구간, 인용 범위, 자막 대조 기록|재인용을 당사자 원문으로 오인, 자막 요약에서 조건 탈락|
|배경음·전환음|자체 녹음, 계약한 라이브러리의 개별 트랙|트랙 ID·사용 채널·라이선스 확인일·편집본 큐시트|구독 종료 후 재출고 조건 누락, 전체 영상에 반복된 음원 미기록|

자료팀의 sources.json은 실제 회차에서 사용한 파일마다 행 하나를 둔다. evidence에는 원문 페이지·계약 증빙 경로나 직접 제작한 원본 경로를 넣는다. 예를 들어 자체 그래프의 source에는 통계 원표, evidence에는 내려받은 원표 버전과 차트 생성 파일, credit에는 설명란에 넣을 출처 문구를 적는다. 검색 결과의 미리보기와 기사 사진을 원본 제작사로 등록하지 않는다.
